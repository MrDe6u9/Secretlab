# 🔐 LocalStorage Secret Lab

A hands-on client-side security lab designed to demonstrate the risks of storing sensitive information in browser storage.

---

## 📌 Lab Information

* **Lab Name:** LocalStorage Secret Lab
* **Difficulty:** Medium
* **Category:** Client-Side Security
* **Created By:** **Adarsh Ramgirwar**
* **Lab link:** https://secretctf.netlify.app/

---

## 🎯 Objective

Analyze the application, understand its behavior, and identify security weaknesses to recover the hidden flag.

---

## 📚 What You Will Learn

* Client-side security fundamentals
* Risks of storing sensitive information in LocalStorage
* Browser storage inspection techniques
* Source code analysis
* Information disclosure vulnerabilities
* JavaScript application analysis
* Identifying exposed client-side secrets
* Understanding encrypted client-side data
* Secure handling of sensitive information in web applications

---

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
